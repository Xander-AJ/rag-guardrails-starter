# Guardrails

Human-facing guide to the safety layer in rag-guardrails-starter.

Covers the four guardrail components and how the pipeline orchestrates them:

- **Input guard** — filtering and sanitizing incoming queries.
- **Emergency detector** — crisis detection and short-circuit routing.
- **Hallucination hooks** — grounding draft answers against retrieved context.
- **Output guard** — validating responses before they reach the user.
